# AI Usage

This project was built with heavy use of AI coding tools, as the task brief explicitly invites.
This file is updated as the project progresses and will be finalized before submission.

## Tools

- **Claude Code (Opus 5)** — used throughout for architecture decisions, scaffolding, and writing
  nearly every file in this repository, driven interactively by the author (turn by turn, not a
  single unattended generation).
- **Anthropic Claude API (vision)** — this is not a coding tool, it's a runtime dependency of the
  app itself: it's the hosted vision-language model that reads title/author text off spine crops.
  Documented in the architecture section of the README, not here.
